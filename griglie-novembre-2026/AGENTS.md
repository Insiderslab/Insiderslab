# Regole per Codex — Griglie novembre 2026

Codex legge questo file in automatico quando lavora in questa cartella.

## Cosa puoi fare
- Leggere i file dei clienti dalla cartella Drive sincronizzata (Google Drive per desktop).
- Scrivere **solo** in `mappe/` e `output/` di questa cartella.
- Usare `ffprobe` / `ffmpeg` per leggere durata e formato dei video ed estrarre fotogrammi in una cartella temporanea (`mappe/_frames/`, da cancellare alla fine).

## Cosa non devi mai fare
- Spostare, rinominare, modificare o cancellare file nelle cartelle dei clienti.
- Aprire `Invoices`, fatture, preventivi, presentazioni commerciali o file con prezzi, password, telefoni, email.
- Leggere "MASTER · Contactos".
- Inviare messaggi, pubblicare, creare righe su Monday.
- Inventare: se un dato manca scrivi `non so` o `da chiedere al cliente`.

## Lingua
- Mappe e griglie interne: italiano (note al team in spagnolo dove indicato nel brief).
- Piano per il cliente: solo italiano, niente note interne, niente nomi del team.

## Un cliente per volta
Lavora su un solo cliente per lancio. Alla fine scrivi un riepilogo di 5 righe: file mappati, file saltati e perché, dubbi.
