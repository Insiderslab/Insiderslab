# Approve by Heili

Seguire `AGENTS.md` e `docs/CONTRATTO.md` per questo progetto.

Per caricare post da Excel, CSV o JSON usare l'interfaccia condivisa con Codex: `scripts/approve_import.py`. Iniziare da `docs/AGENT-IMPORT.md` e `doctor`; poi risolvere il cliente, validare il file e creare le bozze quando autorizzato. Il contratto HTTP è in `docs/AUTOMATION-API.md`. Non saltare i controlli di workspace/versione e non usare i link dei clienti come chiavi API.
