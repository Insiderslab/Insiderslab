# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is a **GitHub special profile repository** (`Insiderslab/Insiderslab`). Because the repo
name matches the account name, its `README.md` is rendered as the profile landing page at
`https://github.com/Insiderslab`.

It is **not** a software project: there is no source code, build system, package manager,
test suite, or CI. The entire deliverable is the rendered `README.md`. Do not add build/lint/test
tooling or scaffold an application here unless the user explicitly asks to repurpose the repo.

## Working in this repository

- The only meaningful file is `README.md`. Edits to it change what visitors see on the profile.
- Markdown is GitHub-flavored. The HTML comment block (`<!--- ... --->`) at the bottom is the
  default GitHub template hint and is intentionally hidden from the rendered page — keep it or
  remove it, but know it does not display.
- There is nothing to compile or run. "Testing" a change means previewing the Markdown (e.g. via
  GitHub's preview, or any local Markdown renderer).

## Conventions

- The README is written in the first person as the profile owner (`@Insiderslab`); preserve that
  voice and the emoji-prefixed bullet style when editing.
- The contact address shown publicly is `info@insiderslab.it`. Keep public-facing contact details
  consistent with what's already in the README.
